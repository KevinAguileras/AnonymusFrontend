# Integración con AWS RDS

El frontend ahora consulta la API Spring Boot para usuarios, catálogo y compras.
La configuración local usa IntelliJ en el puerto 8081. Ver los pasos actualizados
para ejecutar, demostrar y probar en [INTEGRACION_AWS.md](INTEGRACION_AWS.md).

Node 24 recomendado. En este computador ya está preparado `bash ejecutar.sh dev`
y `bash ejecutar.sh test:coverage -- --browsers ChromeHeadlessCI`. En otros equipos
instalar Node 24 y usar `npm ci`, `npm run dev` y `npm run test:coverage`.
La documentación original de las entregas anteriores se conserva a continuación;
las instrucciones de integración enlazadas arriba reemplazan el comportamiento local simulado.
